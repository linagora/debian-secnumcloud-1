# ADR template

Copy this block into a new file `docs/adr/NNNN-short-title.md`:

```markdown
# ADR-NNNN: Short decision title

- **Status**: Proposed | Accepted | Rejected | Deprecated | Superseded by ADR-XXXX
- **Date**: YYYY-MM-DD
- **Deciders**: names
- **Related issue**: #N

## Context

What is the problem? Which constraints (technical, regulatory, SecNumCloud, schedule) apply?

## Considered options

### Option 1: name

- Pros: ...
- Cons: ...

### Option 2: name

- Pros: ...
- Cons: ...

## Decision

The chosen option and the main rationale.

## Consequences

What becomes easier, what becomes harder, and the follow-up actions.
```
