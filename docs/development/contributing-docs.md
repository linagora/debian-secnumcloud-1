# Contributing to the documentation

The documentation is written in Markdown in the `docs/` directory and generated by [Zensical](https://zensical.org). It is published automatically to <https://linagora.github.io/debian-secnumcloud-1/> on every merge to `main`.

## Local preview

Prerequisite: Python 3.10 or later.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-docs.txt
.venv/bin/zensical serve
```

The site is served at <http://localhost:8000> and reloads on every change.

Before opening a PR, check that the build passes in strict mode, as in CI:

```sh
.venv/bin/zensical build --clean --strict
```

## Adding a page

1. Create a `.md` file in the directory of the relevant section, e.g. `docs/administration/backup.md`. Use lowercase file names, words separated by hyphens.
2. Start the file with a level-1 heading (`# Title`).
3. Reference the page in `nav` in `zensical.toml`, at the desired position.
4. Use **relative links to `.md` files** (e.g. `[YubiKey](../administration/yubikey.md)`): the strict build reports broken links.
5. Open a pull request. CI builds the site; the PR cannot be merged if the build fails.

## Special cases

- **Architecture decision**: write an ADR from the [ADR template](../adr/template.md).
- **Experiment**: add an entry to the [R&D journal](../rd-journal/index.md) from the [template](../rd-journal/template.md).

## Useful formatting

```markdown
!!! warning "Warning"
    Warning admonition (also: note, info, tip, danger).

=== "Debian"
    Tab content

- [x] Task list
```

Mermaid diagrams are supported through a ` ```mermaid ` code block.
