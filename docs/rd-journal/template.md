# R&D journal entry template

Copy this block into a new file `docs/rd-journal/YYYY-MM-DD-topic.md`:

```markdown
# YYYY-MM-DD: Experiment topic

- **Author**: name
- **Related issue**: #N
- **Outcome**: Works | Partially works | Does not work

## Goal

What we are trying to verify or achieve.

## Experiment

Environment (versions, hardware, VM), steps followed, commands run.

## Outcome

What was observed. Include relevant log excerpts.

## Cause

Why it works, partially works or does not work.

## Next steps

Leads, ADRs to write, issues to open.
```
